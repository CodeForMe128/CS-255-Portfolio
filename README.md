# CS-255-Portfolio

Briefly summarize the DriverPass project. Who was the client? What type of system did they want you to design?

DriverPass was a project in which a software app for Liam and Ian’s driving school was created. They wanted a system that would operate in the cloud and be able to schedule lessons for customers, track employees, and vehicles.


What did you do particularly well?

My strength was in doing a very good job in drawing UML diagrams for showing how the system works.


If you could choose one part of your work on these documents to revise, what would you pick? How would you improve it?

The non functional requirements could have been improved in providing detailed information about security and also performance issues. Better detail on that matter would allow the developers to have clear limits when implementing the cloud infrastructure.


How did you interpret the user's needs and implement them into your system design? Why is it so important to consider the user's needs when designing?

I understood the needs of the user through studying the client's scenario and changing it to use cases. Its important to keep in mind the needs of the user while designing to make sure that the software solves the clients problems.


How do you approach designing software? What techniques or strategies would you use in the future to analyze and design a system?

I begin by having complete knowledge about the business requirements prior to the visualization modeling stage. In the future, I am going to use UML modeling for the purposes of laying down the system requirements before starting coding, since this is an efficient way to avoid structural issues in the development process.
